🇰🇷 Coupang — ขายของบน Marketplace อันดับ 1 เกาหลี จนรับเงินครบ

55 ขั้นตอน ใน 9 ส่วน | Marketplace อันดับ 1 เกาหลี 30M+ Users | Rocket Delivery

ส่วนที่ 1 — สมัครและเตรียมเอกสาร (5 ขั้น)

  1. สมัครบัญชีผู้ใช้ที่ coupang.com เพื่อทำความเข้าใจฝั่งผู้ซื้อก่อน
  2. เตรียมเลขทะเบียนธุรกิจเกาหลี (사업자등록번호) — ผู้ขายต่างชาติใช้ Coupang Global Selling หรือจดนิติบุคคล/ตัวแทนในเกาหลี
  3. เตรียมใบแจ้งประกอบธุรกิจขายทางออนไลน์ (통신판매업 신고)
  4. เตรียมบัญชีธนาคารเกาหลี หรือ Payoneer สำหรับรับ Settlement
  5. เตรียมอีเมลธุรกิจ + เบอร์ติดต่อสำหรับยืนยันตัวตน

ส่วนที่ 2 — สมัคร Coupang Wing (Seller Portal) (8 ขั้น)

  1. ไปที่ wing.coupang.com → กด "입점 신청" (สมัครเป็นผู้ขาย)
  2. เลือกประเภทผู้ขาย: Marketplace Seller หรือ Rocket Growth
  3. กรอกข้อมูลธุรกิจ: ชื่อร้าน / หมวดสินค้า / ที่อยู่
  4. อัปโหลดเอกสาร: ทะเบียนธุรกิจ / 통신판매업 신고증 / Passport (ต่างชาติ)
  5. ผูกบัญชีธนาคารสำหรับรับ Settlement
  6. ยอมรับข้อตกลงผู้ขาย Coupang (이용약관)
  7. รอ Coupang ตรวจสอบและอนุมัติ 3–7 วันทำการ
  8. เข้าใช้งาน Coupang Wing Dashboard หลังได้รับอนุมัติ

ส่วนที่ 3 — เลือกโมเดล Fulfillment และตั้งค่าร้าน (6 ขั้น)

  1. เลือกโมเดลจัดส่ง: Seller-Fulfilled (ส่งเอง) หรือ Rocket Growth (ส่งเข้าคลัง Coupang)
  2. Rocket Growth: จองและส่งสต็อกเข้า Fulfillment Center ของ Coupang
  3. ตั้งค่าขนส่งฝั่งผู้ขาย: CJ Logistics / Hanjin / Lotte + ค่าส่ง
  4. ตั้งค่านโยบายคืน/เปลี่ยนสินค้า (반품/교환) ตามมาตรฐานเกาหลี
  5. ตั้งข้อมูลติดต่อฝ่ายบริการลูกค้า (CS) ภาษาเกาหลี
  6. ตั้งค่าเวลาจัดส่งและวันหยุดร้านใน Wing

ส่วนที่ 4 — เพิ่มสินค้าและ Listing (9 ขั้น) 🤖

  1. Wing → 상품관리 → เพิ่มสินค้าใหม่ (상품 등록)
  2. เลือกหมวดหมู่สินค้าให้ตรง (สำคัญต่อการค้นเจอ)
  3. ตั้งชื่อสินค้าภาษาเกาหลี: Keyword + จุดเด่น 🤖
  4. อัปโหลดรูปสินค้า: Main Image + รูปรายละเอียด (ตามสเปก Coupang)
  5. สร้าง Detail Page (상세페이지) แบบ Infographic 🤖
  6. ตั้งค่า Options / Variant: สี / ขนาด / จำนวน
  7. ตั้งราคา KRW + ราคาโปรโมชั่น (ระวังระบบ Item Winner)
  8. ตั้งสต็อกและรหัส SKU / Barcode
  9. Submit สินค้ารอ Coupang อนุมัติ 24–48 ชั่วโมง

ส่วนที่ 5 — ชนะ Item Winner และ Search Ranking (5 ขั้น) 🤖

  1. เข้าใจระบบ Item Winner: หลายผู้ขายในลิสต์เดียว ราคาดี+รีวิวดี+ส่งเร็วชนะ Buy Box
  2. วิจัย Keyword ภาษาเกาหลีสำหรับสินค้าไทย 🤖
  3. ใส่ Keyword ในชื่อสินค้า + หมวด + แท็กให้ครบ 🤖
  4. ปรับราคา/ค่าส่ง/เวลาส่งให้แข่งขันได้เพื่อชิง Item Winner
  5. ติดตามอันดับค้นหาและ Conversion ใน Wing Analytics

ส่วนที่ 6 — โปรโมชั่นและ Marketing (6 ขั้น)

  1. สร้าง Coupon ส่วนลด (할인쿠폰): % หรือลดราคาคงที่
  2. เข้าร่วม Coupang Deal / 로켓와우 สำหรับสมาชิก Wow
  3. ตั้ง Bundle / ซื้อหลายชิ้นราคาพิเศษ
  4. เข้าร่วมแคมเปญตามฤดูกาล: 설날 / 추석 / 11.11
  5. ให้ Coupang Cash / Point จูงใจการซื้อซ้ำ
  6. ทำคอนเทนต์นอกแพลตฟอร์ม (Naver Blog / SNS) ดึงทราฟฟิกเข้าลิสต์

ส่วนที่ 7 — Coupang Ads (5 ขั้น)

  1. เข้า Wing → 광고관리 → สร้าง Coupang Ads Account
  2. เลือกชนิดโฆษณา: Auto (อัตโนมัติ) หรือ Manual (เลือก Keyword เอง)
  3. ตั้ง Bid ต่อ Keyword และงบโฆษณาต่อวัน
  4. เลือกสินค้าที่จะโปรโมทให้ตรง Search Intent
  5. ติดตาม ROAS / CPC / Conversion และปรับ Bid

ส่วนที่ 8 — รับออร์เดอร์และจัดการจัดส่ง (6 ขั้น)

  1. รับ Notification ออร์เดอร์ใหม่ใน Coupang Wing
  2. ตรวจสอบรายละเอียด: สินค้า / จำนวน / ที่อยู่
  3. ยืนยันออร์เดอร์และเตรียมสินค้าตาม SLA ของ Coupang
  4. Seller-Fulfilled: แพ็ค + พิมพ์ใบปะหน้า + ส่งกับขนส่งที่ผูกไว้ / Rocket Growth: Coupang จัดส่งให้
  5. อัปเดตเลข Tracking ในระบบให้ทันเวลา (สำคัญต่อคะแนนร้าน)
  6. ดูแลอัตราส่งตรงเวลาและอัตรายกเลิกให้อยู่ในเกณฑ์ Coupang

ส่วนที่ 9 — Settlement รับเงิน และรีวิว (5 ขั้น) 🤖

  1. ลูกค้าชำระผ่าน Coupang (บัตร / 계좌이체 / Coupay)
  2. เงินเข้ารอบ Settlement ของ Coupang (โอนตามรอบ ~เดือน หลังส่งมอบ)
  3. โอนเงินจาก Settlement เข้าบัญชีธนาคาร / Payoneer แล้วแลก KRW → THB
  4. ตอบและดูแลรีวิวลูกค้าทุกรายการ (รีวิวมีผลต่อ Item Winner มาก) 🤖
  5. วิเคราะห์ยอดขาย/รีวิวใน Wing Analytics แล้วปรับ Listing + ราคา
