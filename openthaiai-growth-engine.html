OpenThaiAI Studio รองรับการติดตั้งเป็น App ผ่าน PWA และ Capacitor สำหรับ iOS/Android
1

เปิด Chrome บน Android

ไปที่ app.openthaiai.com ผ่าน Chrome (ต้องใช้ Chrome เท่านั้น)

2

แตะเมนู ⋮ แล้วเลือก "Add to Home screen"

หรือระบบจะแสดง banner "ติดตั้ง OpenThaiAI Studio" ให้กดได้เลย

3

กด "Add" เพื่อยืนยัน

App จะปรากฏบน Home Screen พร้อมไอคอนเหมือน App จริง เปิดแบบ fullscreen ไม่มีแถบ browser

4

รับ Push Notification

เมื่อเปิด App ครั้งแรก อนุญาต notification เพื่อรับแจ้งเตือนเมื่องาน AI เสร็จ

1

เปิด Safari บน iPhone/iPad

ต้องใช้ Safari เท่านั้น (Chrome บน iOS ไม่รองรับ PWA install)

2

แตะปุ่ม Share ☐↑

ปุ่ม Share อยู่กลางแถบล่าง — แตะแล้ว scroll ลงในเมนู

3

เลือก "Add to Home Screen"

แก้ชื่อได้ตามต้องการ แล้วกด "Add" มุมบนขวา

4

iOS 16.4+ รองรับ Push Notification

ต้องเปิดจาก Home Screen ก่อน แล้วกด Allow เมื่อระบบถาม

1

เปิด Chrome หรือ Edge

ไปที่ app.openthaiai.com — ทั้ง Windows, Mac, Linux รองรับ

2

คลิกไอคอน Install ในแถบ URL

Chrome จะแสดงไอคอน ⊕ ในแถบ URL — คลิกแล้วเลือก "Install"

3

App เปิดในหน้าต่างแยก

มี taskbar icon / Dock icon แยกต่างหาก ใช้งานได้เหมือน native app

1

ติดตั้ง Capacitor

npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios

2

Init Capacitor project

npx cap init OpenThaiAI com.openthaiai.app --web-dir=out

3

เพิ่ม platforms

npx cap add android · npx cap add ios — แล้ว build Next.js: npm run build && npm run export

4

Sync และเปิดใน IDE

npx cap sync → npx cap open android (Android Studio) หรือ npx cap open ios (Xcode) แล้ว build + submit store

5

Push Notification ผ่าน Firebase/APNs

ติดตั้ง @capacitor/push-notifications เชื่อม Firebase (Android) และ APNs (iOS) — backend ส่งผ่าน Celery task

📦 Docker Deploy (1 คำสั่ง)
git clone https://github.com/openthaiai/engine && cd engine && cp .env.example .env && docker compose up -d

ระบบจะ deploy ทั้ง API, Worker, Beat Scheduler, Flower Monitor, Frontend PWA และ Nginx ในคำสั่งเดียว รองรับ VPS, Cloud (AWS/GCP/DO), หรือ Mac mini บ้านคุณเอง
